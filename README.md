# DE_Uni-Stundenplan-Uni-Timetable

大学课程表与学分成绩管理微信小程序。克隆或下载后，在微信开发者工具中导入仓库根目录（可直接看到 project.config.json）。

包含周课表、PDF/链接导入、冲突并排、拖动、节假日、地图入口、批注、PDF导出、学期档案，以及按模块分组的成绩与ECTS管理。

代码沿用当前最终版本。云环境及AppID属于原项目；其他开发者需改为自己的配置并部署云函数。成绩和课表保存在设备本地。图片OCR仍需要单独配置受限调用身份，配置方法见使用说明。

请先阅读 [导入与云部署说明](先看这里_导入与云部署.md)。
验证范围见 [验证记录](验证记录.md)。

- miniprogram：小程序界面、课表逻辑、假期与本地 PDF 导出
- cloudfunctions/parseSchedule：学校文本 PDF 与公开 PDF 链接解析
- checks：开发验证脚本，不参与小程序运行

当前版本没有预置课程或学校名称。云环境配置在 miniprogram/config.js，界面不显示环境输入框。云函数已创建，实际连通性见验证记录。

新增学期课表档案与成绩学分页面，详见 [使用说明](学期档案与成绩_使用说明.md)。成绩文字PDF解析及图片OCR复用 parseSchedule 云函数，更新时需部署整个函数目录。
