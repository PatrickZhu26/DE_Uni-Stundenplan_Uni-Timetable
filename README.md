# DE_Uni-Stundenplan_Uni-Timetable

大学课程表与学分成绩管理微信小程序。克隆或下载后，在微信开发者工具中导入仓库根目录（可直接看到 project.config.json）。

包含周课表、PDF 与 iCalendar（ICS）导入、冲突并排、拖动、节假日、地图入口、批注、PDF导出、学期档案，按模块分组的成绩与ECTS管理、课程取消日期、简洁显示，以及考试与作业提醒。

课程块内可直接滚动阅读全部信息，到达上下边界后衔接整页滚动；保留横向滑动、拖动和静止长按删除确认。云环境及AppID属于原项目；其他开发者需改为自己的配置并部署云函数。成绩和课表保存在设备本地。图片OCR仍需要单独配置受限调用身份，配置方法见使用说明。

请先阅读 [导入与云部署说明](先看这里_导入与云部署.md)。

- miniprogram：小程序界面、课表逻辑、假期与本地 PDF 导出
- cloudfunctions/parseSchedule：学校文本 PDF、ICS 文件和公开导出链接解析
- checks：开发验证脚本，不参与小程序运行

当前版本没有预置课程或学校名称。云环境配置在 miniprogram/config.js，界面不显示环境输入框。

新增学期课表档案与成绩学分页面，详见 [使用说明](学期档案与成绩_使用说明.md)。成绩文字PDF解析及图片OCR复用 parseSchedule 云函数，更新时需部署整个函数目录。

首页提供💡使用说明，阅读文案见 [使用说明](使用说明_可修改文案.md)。课程表和成绩单PDF导入保留聊天文件入口；手机本地文件需先分享到微信，不能通过存储授权直接调出系统文件选择器。

## 2026-11-02 更新

加入按课程勾选取消日期的月历、自动同步的学期档案、课表/成绩分别清空、单份或全部档案删除、编辑返回位置恢复、蓝色四角星切换简洁信息版、简称和并列课程主要显示选择，以及课程内考试与作业计划。未完成作业在课表上显示到截止时间，过期隐藏提醒并保留记录。提醒仅在小程序内显示。

开启手机和平板横竖屏和桌面窗口调整，按窗口宽度重新计算课表。本次无需更新云函数。新增检查：`node checks/course-updates.js`。

### 第二轮界面与单学期管理更新

平板完整/简洁课表与学期档案按实际容器宽度排满整周，冲突课程不扩宽当天列；两行日期导航统一对齐。主要显示选项仅在简洁版存在真实课程冲突时出现。作业提醒固定在课程块顶部，点击可直接进入本课作业。长按专业与学期标题可确认清空单个学期，保留其他学期和独立课表数据。专项检查：`node checks/tablet-reminders.js`。

### 第三轮：主要显示即时生效与档案操作对齐

已保存课程的主要显示开关立即保存并同步学期档案，直接返回即可看到新的主要课程；同时间冲突的旧主要选择自动取消，其他编辑草稿独立保存。识别预览保留选择，追加导入时优先采用新选择。档案卡片的标题与保存信息可自动换行，删除按钮固定在内容区右侧。回归检查：`node checks/primary-choice.js`。

### 1.1.0：窗口适配与兼容性检查

四个页面补齐横屏左右安全区，适配旋转时系统尺寸暂时未刷新的情况。宽屏说明、成绩表单和按钮使用稳定字号，取消日期月历与成绩弹窗限制在窗口高度内并允许滚动。布局检查扩展到280–2560像素的23种宽度，另以自定义手机、平板和电脑窗口核对原生布局与事件恢复。

### 1.2.0：近期考试与作业、学校日历导入

- 日期栏下方汇总近期考试和作业。点开记录可查看详情，从卡片齿轮进入编辑，保存或返回后回到列表。

- 导入后显示德国当前周。日期、周次和到期提醒按欧洲柏林时区更新。
- 改进手机、平板和电脑窗口中的课表设置表单与文字排版。
